# PClaude Installer

Desktop MVP for checking local prerequisites and saving Anthropic configuration for PClaude.

## Development

- `npm install`
- `npm run dev`
- `npm run dev:electron`
- `npm test`
- `npm run lint`
- `npm run build`

## MVP Scope

- Detect Node.js, npm, Git, and Claude CLI availability.
- Save Anthropic API settings after a connectivity check.
- Offer a placeholder install flow for missing or outdated core dependencies.
- Produce renderer and Electron bundles for release packaging.
